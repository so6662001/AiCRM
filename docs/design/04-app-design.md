# AiCRM 移动端 APP 设计文档

## 1. 技术方案

### 1.1 技术选型

| 项目 | 方案 | 说明 |
|---|---|---|
| 框架 | UniApp (Vue3 + TypeScript) | 跨平台，一套代码运行 Android/iOS |
| UI 组件库 | uView Plus / uni-ui | 适配 UniApp 的组件库 |
| 状态管理 | Pinia | Vue3 推荐状态管理 |
| 网络请求 | 封装 uni.request | 统一请求拦截、鉴权、错误处理 |
| 地图定位 | 高德地图 SDK | 签到定位、地理围栏 |
| 推送通知 | UniPush 2.0 | 消息推送 |
| 录音采集 | 原生插件 (Android/iOS) | 通话录音自动采集 |
| 本地存储 | uni.setStorageSync | 离线数据缓存 |

### 1.2 原生能力需求

由于 APP 需要以下原生能力，需要开发原生插件：

```
┌─────────────────────────────────────────────────────────┐
│                    原生插件清单                           │
│                                                          │
│  1. 通话录音插件（Android）                               │
│     - 自动检测外呼/接听                                   │
│     - 通话开始时自动录音                                   │
│     - 通话结束后上传录音文件                               │
│     - 关联客户电话号码自动匹配                             │
│                                                          │
│  2. 企业微信录音插件                                      │
│     - 对接企业微信会话存档 API                             │
│     - 自动采集语音消息                                     │
│                                                          │
│  3. 位置服务插件                                          │
│     - 后台持续定位（外勤模式）                             │
│     - 地理围栏（客户位置自动签到提醒）                      │
│     - 省电模式优化                                        │
│                                                          │
│  4. 拍照插件                                              │
│     - 签到拍照（自动加水印：时间+地点）                     │
│     - 图片压缩上传                                        │
│                                                          │
│  注意：iOS 系统限制，不支持通话自动录音，                    │
│  需用户手动上传或使用其他方案（如外呼设备录音）              │
└─────────────────────────────────────────────────────────┘
```

## 4. 不同拜访方式的材料要求

| 拜访方式 | 必须提交材料 | 可选材料 | 自动采集 |
|---|---|---|---|
| 现场拜访 | 签到打卡（GPS+照片）、拜访结果 | 现场照片、文件 | GPS 位置、签到时间 |
| 电话拜访 | 通话记录、拜访结果 | 手动备注 | 通话录音（自动）、通话时长 |
| 微信拜访 | 聊天截图、拜访结果 | 文件附件 | - |
| 企业微信 | 拜访结果 | 截图、文件 | 会话记录（企业微信API）、语音录音 |
| 视频会议 | 会议纪要、拜访结果 | 会议录屏 | - |

```
     │               │               │               │  │
     │               │               │               │◀─┘
     │               │               │  分析结果回写    │
     │               │               │◀──────────────│
     │               │               │               │
     │  ← 通知用户：录音已分析完成 ←    │               │
     │                                               │
     │  如有违规，推送违规警报                          │
     │◀──────────────────────────────────────────────│
```

**号码自动匹配逻辑**：
1. 通话发生时，APP 获取对方号码
2. 通过客户联系人电话库自动匹配客户
3. 如匹配成功，录音自动关联到该客户
4. 如匹配失败，录音标记为"未匹配"，可手动关联

## 7. 推送通知策略

| 通知类型 | 触发场景 | 推送方式 | 优先级 |
|---|---|---|---|
| 线索分配 | 运营/经理分配线索 | APP Push + 系统消息 | 高 |
| 任务安排 | 上级创建任务 | APP Push + 系统消息 | 高 |
| 任务到期提醒 | 任务即将到期 | APP Push | 中 |
| 违规警报 | AI 检测到违规用词 | APP Push + 系统消息 | 紧急 |
| 审核通知 | 客户审核结果 | APP Push + 系统消息 | 中 |
| 客户跟进提醒 | 到达计划跟进时间 | APP Push | 中 |
| ERP 同步结果 | 客户同步完成 | 系统消息 | 低 |
